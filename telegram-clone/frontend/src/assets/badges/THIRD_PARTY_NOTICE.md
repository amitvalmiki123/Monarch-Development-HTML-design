# Third-party base animation (recolored)

`verified-badge.json` in this folder started from the **`lottie-emojis`** npm
package (https://www.npmjs.com/package/lottie-emojis,
https://github.com/typeofNaN/lottie-emojis) by typeofNaN, published under the
**MIT License** — specifically its "Check mark button" (✅) animation, which
is an independently-created animation (not Telegram's own animated emoji/
badges, not extracted from any Telegram client or mod APK).

It has been **modified** here: the original green button colors were
programmatically recolored to FairyChat's blue (#3ba7ff-family) palette so it
reads as a "verified" checkmark badge instead of the green check-mark-button
emoji, for use as the animated FairyChat Premium "Profile Badge" option
(pop-in + shine-sweep motion, looping). The checkmark shape, timing/keyframe
data, and overall composition are otherwise unchanged from the upstream file.
