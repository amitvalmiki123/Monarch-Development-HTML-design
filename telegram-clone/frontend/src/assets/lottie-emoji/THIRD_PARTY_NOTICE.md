# Third-party animated emoji

The `.json` files in this folder are a curated subset of the **`lottie-emojis`**
npm package (https://www.npmjs.com/package/lottie-emojis,
https://github.com/typeofNaN/lottie-emojis) by typeofNaN, published under the
**MIT License**. They are an independently-created animated emoji set (not
Telegram's own animated emoji/stickers, not extracted from any Telegram
client or mod APK) — used here as a legitimate, freely-licensed way to get
real Lottie-quality animated emoji into FairyChat's Premium features
("Animated Emojis" / "Emoji Status") instead of relying on plain CSS
transforms on static Unicode glyphs.
